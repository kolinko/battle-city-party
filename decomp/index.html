What is source, and what is a driver?

game.py is a Python-style source language. It is not ordinary CPython and it is not the original authors' code: it was recovered from the cartridge's machine code. bpyc.py compiles the current function bodies, and it is exactly the same file in the browser and in the repository.

game.bpy holds the technical output and the console schedule. The interpreter executes it without falling back to the original opcodes. The video, sound and data-encoding drivers stay technical.

The equivalence checks refer to the pinned jsnes emulator model and the recorded scenarios, not to every possible input or to a physical NES.

Offline: run decomp/start.py and open the address it prints. That server only serves local files; compiling still happens in the browser.
